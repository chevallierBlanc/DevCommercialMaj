# CommercialMagDb.Api

API de synchronisation séparée du projet WinForms et du dashboard web.

## Rôle

- authentification JWT
- synchronisation des sorties
- synchronisation des dépenses
- alimentation du dashboard patron

## Solution dédiée

- `CommercialMagDb.Api.sln`

## Lancement

- `dotnet run`
- ou ouverture dans Visual Studio via `CommercialMagDb.Api.sln`

## Configuration

Les paramètres principaux sont dans:

- `appsettings.json`
- `appsettings.Development.json`

## Base cible

- `CommercialMagCloudDB`
