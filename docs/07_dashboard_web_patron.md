# Dashboard Web Patron

Le dashboard patron doit être un projet séparé de l'ERP WinForms et de l'API.

## Technologie

- ASP.NET Core MVC ou Blazor Web App

## Contraintes

- aucune saisie métier
- aucune modification des données
- aucune connexion directe à la base locale de l'ERP
- consommation exclusive de l'API

## Emplacements

- projet web: `prototype/DashboardWebPatron`
- API: `prototype/ApiCommercialMagDB`
- ERP WinForms: `prototype/WinFormsVB/DevCommerc8ak`

## Scénarios

- consultation desktop
- consultation mobile
- mode TV plein écran
